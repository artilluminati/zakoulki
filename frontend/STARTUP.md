# Закоулки — MVP

FastAPI backend + Next.js frontend. Карта на JavaScript API Яндекс Карт
оформлена как рабочий стол Windows XP; остальные страницы (главная,
логин/регистрация, профиль, карточка места) — в современном тёмном стиле.

## Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # поправьте DATABASE_URL/SECRET_KEY при необходимости

# создаём postgres-базу заранее (например, createdb zakoulki)

alembic revision --autogenerate -m "init"
alembic upgrade head

python -m app.db.seed       # наполняет города и категории

uvicorn app.main:app --reload
```

Backend поднимется на `http://localhost:8000`, документация — `http://localhost:8000/docs`.

Хэширование паролей — через `pwdlib[argon2]` (см. `app/core/security.py`).

## Frontend

```bash
cd frontend
npm install
cp .env.local.example .env.local
```

Впишите в `.env.local` бесплатный ключ JavaScript API Яндекс Карт
(https://developer.tech.yandex.ru/ → «Подключить API» → «JavaScript API и
HTTP Геокодер»):

```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=ваш_ключ
```

```bash
npm run dev
```

Frontend — `http://localhost:3000`.

## Карта страниц

| Маршрут | Что там |
|---|---|
| `/` | Выбор города + лента последних находок |
| `/login`, `/register` | Отдельные полноэкранные формы входа/регистрации |
| `/profile` | Профиль: мои места и мои публикации по всем городам |
| `/map/[citySlug]` | Рабочий стол Windows XP с картой |
| `/place/[slug]` | Карточка места: галерея, публикации, добавление/редактирование/удаление своих публикаций |

### Рабочий стол карты (`/map/[citySlug]`)

- **Фильтры** — поиск по названию, «показать места рядом со мной» (браузерная
  геолокация, радиус 3 км, отдельная метка «вы здесь» на карте), переключатель
  «только с фото», чекбоксы категорий (список со скроллом, любое количество).
  Переключатель города — выпадающий список в таскбаре, без выхода на главную.
- **Добавить место** — выбор точки на карте, название, категории,
  **обязательная** первая публикация (текст + минимум одна фотография).
  Место появляется на карте только после того, как всё это опубликовано.
- **Мои места** — список своих мест с инлайн-редактированием (название,
  категории, перенос точки на карте) и удалением, плюс ссылка «открыть
  страницу места».
- **Аккаунт** — вход/регистрация или профиль с кнопкой «Выйти» и ссылкой в
  `/profile`.
- Окна двигаются за заголовок, тянутся за правый нижний угол, на узких
  экранах (< 640px) разворачиваются на весь экран без ручек изменения размера.

### Карточка места (`/place/[slug]`)

- Slug генерируется на латинице автоматически (кириллица транслитерируется
  в `app/api/routes/places.py`, `slugify()`).
- Бэкенд отдаёт место по slug (`GET /api/places/slug/{slug}`), а не только по
  числовому `id`.
- Фотогалерея из всех публикаций (клик — полноразмерный просмотр),
  лента публикаций с автором и датой.
- Авторизованный пользователь может добавить новую публикацию (текст +
  необязательные фото), отредактировать или удалить свои же публикации, а
  также удалить отдельную фотографию из своей публикации, не трогая остальные.
- В балуне метки на карте показывается обложка места (`place.cover_photo` —
  первое фото первой публикации, вычисляется на бэкенде).

### Инфраструктура интерфейса

- `lib/auth.tsx` — контекст авторизации (JWT в `localStorage`, проверка через
  `GET /api/auth/me`), обёрнут вокруг всего приложения.
- `lib/toast.tsx` — единая система уведомлений об успехе/ошибке вместо
  разрозненного инлайн-текста в каждой форме.
- `lib/errors.ts` — `getApiError()` приводит любой формат ошибки FastAPI
  (строка / объект валидации / список объектов при 422) к читаемой строке.
- `lib/useIsMobile.ts` — отвечает за адаптивное поведение плавающих окон.
- Иконки — `lucide-react` везде вместо эмодзи (эмодзи периодически терялись
  при сохранении файлов в некоторых редакторах/тулчейнах — SVG-иконки от
  этого не зависят).
- Шрифт — `Inter` через `next/font/google`, подключён в `app/layout.tsx`.
- `app/icon.tsx` — иконка вкладки браузера генерируется на лету (без бинарного `.ico`).
- `app/not-found.tsx`, `app/loading.tsx` — стилизованные 404 и общий лоадер.

## Соответствие ТЗ — что реализовано, а что ещё нет

Готово: регистрация/авторизация, выбор и переключение города, карта с
просмотром/поиском/фильтрацией мест (категории, «только с фото», «рядом со
мной» через геолокацию), создание/редактирование (включая перенос координат)
/удаление места, создание/редактирование/удаление публикации (включая
удаление отдельных фотографий), загрузка нескольких фото, привязка
нескольких категорий к месту.

Пока не реализовано (осознанные упрощения MVP):

- восстановление доступа/сброс пароля (в ТЗ помечено как «будущее развитие»)
- заменить bounding-box фильтр радиуса на PostGIS `ST_DWithin`, когда база вырастет
- иконки категорий (`category.icon`, например `street-art`/`abandoned`) в
  базе есть, но нигде в интерфейсе не отрисовываются — сейчас только текстовое
  название категории

### Место создано до перехода на латинские slug?

```bash
cd backend
python -m app.db.regenerate_slugs
```

Пересчитает slug всех существующих мест через транслитерацию, аккуратно
обходя коллизии. Безопасно запускать повторно.
