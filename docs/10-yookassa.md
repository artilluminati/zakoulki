# ЮKassa: приём донатов

Сейчас через ЮKassa принимаются **только донаты**. Два назначения:

1. **На поддержку проекта** — «просто так», за это донат получает бейдж «Поддержал проект»;
2. **За рекомендацию** — оплата размещения в блоке «Кто поможет» (после оплаты заявка
   уходит модератору, он публикует её).

## 1. Зарегистрировать магазин

1. Открой [юkassa.ru](https://www.yu-kassa.ru) → «Создать магазин».
2. Заполни: название, адрес сайта, email для уведомлений, телефон.
3. При регистрации ЮKassa предлагает **тестовый режим** — его и бери:
   тестовые платежи работают без привязки карты и без реальных денег.
4. После регистрации: **Настройки → API-ключи**. Там два ключа:
   - `shop_id` (например `123456`) — идентификатор магазина;
   - `secret_key` — секретный ключ (начинается с `test_` для тестового режима).
   Скопируй оба — они понадобятся в `.env`.
5. Чтобы принимать настоящие платежи, нужно пройти проверку (документы, расчётный счёт).
   Это отдельная история — для защиты проекта хватает тестового режима.

## 2. Включить в проекте

В `backend/.env`:

```env
YOOKASSA_ENABLED=true
YOOKASSA_SHOP_ID=123456
YOOKASSA_SECRET_KEY=test_XXXXXXXXXXXX
YOOKASSA_RETURN_URL=https://твой-домен.ru/donate?paid=1
DONATION_MIN=50
DONATION_MAX=100000
DONATION_BADGE_MIN=100     # от какой суммы выдаётся бейдж «Поддержал проект»
DONATION_SPONSOR_MIN=1000  # от какой суммы бейдж «Спонсор проекта»
```

Перезапусти бэкенд и проверь: `curl -s http://127.0.0.1:8000/health` → `"payments": "on"`.

## 3. Вебхук (обязательно)

ЮKassa сообщает об оплате по HTTP — без этого бэк не узнает, что деньги пришли.

В личном кабинете ЮKassa: **Настройки → Уведомления → Добавить уведомление**:

- тип: `Событие платежа` (`payment.succeeded`);
- URL: `https://твой-домен.ru/api/donations/webhook`;
- включите события `payment.succeeded` и `payment.canceled`.

Если до запуска на сервере хочется проверить локально, подставь туннель
(например `https://zakoulki.serveousercontent.com/api/donations/webhook`) и не забудь
потом поменять URL на боевой.

Как это работает: вебхук приходит → сервер **сам** спрашивает у ЮKassa статус платежа
(`GET /v3/payments/{id}`) и сверяет сумму → только после этого донат помечается оплаченным,
начисляется бейдж и приходит письмо «Спасибо за поддержку». Повторный вебхук не ломает
ничего: платёж уже оплачен, повторно бейдж не выдаётся.

## 4. Проверить, что работает

1. Зайди на `/donate`, выбери сумму, нажми «Поддержать».
2. Должно открыться окно ЮKassa (тестовый режим) — можно оплатить тестовой картой
   `4276 3800 0000 0000` (любая сумма, срок — любая будущая дата, CVC — 000).
3. После оплаты вернись на сайт: у доната статус «оплачен», в профиле появился бейдж
   «Поддержал проект», пришло письмо.
4. В админке (`/admin` → «Донаты») видно платёж, сумму, статус и отметку «бейдж выдан».

## 5. Что с деньгами дальше

- Деньги приходят на расчётный счёт, привязанный к магазину в ЮKassa.
- Вывод — по правилам ЮKassa и банка.
- Если платёж нужно отменить: в админке пометить донат как «возврат» (статус `refunded`),
  бейдж при этом снимать стоит вручную через «Бейджи» в админке.
- Чеки: ЮKassa сама присылает чек покупателю на указанный email, ссылка на чек хранится
  в поле `receipt_url` доната.

## 6. Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| «Приём платежей пока не настроен» | `YOOKASSA_ENABLED=false` | включить флаг и перезапустить бэкенд |
| 502 «Платёж не создан» | неверные ключи или нет связи с ЮKassa | проверить `shop_id`/`secret_key`, доступ к api.yookassa.ru |
| Оплатили, но бейдж не выдал | вебхук не настроен или указан неверный URL | проверить URL уведомления в ЮKassa и логи бэкенда |
| Бейдж выдался, письма нет | почта не настроена | см. `docs/09-mail.md` |
