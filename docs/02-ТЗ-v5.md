# Закоулки v5 — ТЗ: геосоцсеть-форум для массового пользователя

> Статус: зафиксировано 09.10.2026. База — v1. v2/v3 — в утиль.
> Разделы: Главная (лента) | Карта | +Создать | Профиль. Первый визит — онбординг.
> Суть: один тред, без жестких типов. Важное (вопрос с точкой/тегами) vs оффтоп (короткий, без обязательной точки).

## 1. Сущности

### Thread
`id, author_id FK, body_md text, body_html text (санитизирован), is_offtop bool (body<=280 и нет place_id), place_id FK nullable (основная точка), views int, created/updated`

Оффтоп: `place_id IS NULL`, живет только в ленте. Вопрос: `place_id NOT NULL ИЛИ >=1 place-mention в тексте`.

### Place (новое, НЕ точка v1)
`id, yandex_kind enum(address/org/geo/self), yandex_id? str, name str (как в ЯК), address?, district?, street?, lat float, lng float, preview_url? (кеш фото ЯК или static-map), created_by, created_at`

Выбор: поиск Яндекс Геокодер + Organizations + свои места. Сохраняем все что отдал Яндекс. Своя точка кликом: kind=self, name="Точка на карте", address=реверс-геокод.

### Mentions
- `@user`: триггер `@`, `thread_user_mentions(thread_id/comment_id, user_id, offset)`
- `#tag`: триггер `#`, `tags(id,name,slug,count) + thread_tags`
- `📍место` / `+место`: триггер `📍` или `+`, `thread_place_mentions(thread_id/comment_id, place_id, offset)`

Авто-теги: `#слово` из текста + словарь ~20 (`отопление→ЖКХ`, `яма→Дороги`). Показ под формой «определили: #ЖКХ [x]».

### Comment
`id, thread_id FK CASCADE, parent_id self nullable (2 уровня), author_id, body_md, body_html, created`. Фото 1 шт в комменте (v1 — можно без).

### Vote/Like/Bookmark/View
Лайки тредов и комментов, закладки тредов, просмотры `+1` с дедупом 24ч.

## 2. Экраны

### 2.1 Онбординг (1 раз)
3 экрана + [Смотреть ленту] [Включить гео] + Пропустить. Флаг localStorage.

### 2.2 Главная `/` — лента
Шапка: лого, поиск с подсказками (5 тредов + 3 места), история 5.
Композер: аватар + «Что происходит рядом?» → `/create`.
Сегмент: Новые | Обсуждают (комменты 24ч) | Рядом (требует гео).
Фильтр-чипы: Все | Важное | Оффтоп + категории.
Карточка: автор+время, тело 4 строки, чип точки `📍 name · 320м` → карта, фото-сетка (двойной тап=лайк), экшн-бар `💬 👍 👁 🔖`, статусов/опросов НЕТ.
Скелетоны, pull-to-refresh, «Вы все прочитали», скролл-restore, cursor-пагинация по 15-20.

### 2.3 Карта `/map` — равный раздел
Светлая ЯК. Поиск адреса, кнопка «где я», чипы-категории.
Кластеры с цифрой (цвет по наличию фото/важности — просто), zoom>=16 — метки-капли / круглые миниатюры с фото.
Тап → bottom-sheet: фото 80 + заголовок + 💬👍расстояние + [Открыть][Маршрут]. Свайп вверх — «рядом еще N».
Кнопка `+ Спросить здесь`: прицел в центре + реверс-адрес «верно?».
Только треды с `lat != NULL`. Ошибка карты не роняет ленту.

### 2.4 Тред `/thread/[id]`
Крошки, H1 (первая строка body или заголовок), мета, тело MD, галерея+lightbox, мини-карта если place_id, ответы плоским списком (Лучшие/Новые), поле ответа sticky, «Лучший ответ» галочка автора (для вопросов), шаринг TG/WhatsApp, `#comment-123` диплинк.

### 2.5 Создание `/create` — 1 экран
Поле текст (авто is_offtop по длине/точке) + фото до 5 (10МБ, сжатие) + toggle «📍 Привязать» (мини-карта + адрес-автокомплит + гео) + категории до 3.
При установке точки → «Ближайшие обсуждения в 300м» (3 шт + [Открыть] + «Это то же место» → reuse place_id).
Черновик в localStorage. Успех → редирект + тост.

### 2.6 Профиль/юзер/auth/admin/tag
Профиль: аватар-инициал, статистика, табы Вопросы|Ответы|Закладки, настройки (имя, город текстом, уведомления).
Auth как есть + «показать пароль» + сила пароля.
`/admin`: таблицы юзеры/треды/категории (бан/скрыть/CRUD) — минимум для вуза.
`/tag/[tag]` оставить.

## 3. Markdown + редактор

Один `MdEditor`: тулбар **B** *I* `</>` ❝ • `@` `📍` 🖼 + хоткеи Ctrl+B/I/K, `@/#/ +` открывают поиск в тексте.
Табы Писать|Просмотр. В комментах — только B/I/ссылка.
Поддержка: bold/italic/code/quote/list/[link]/переносы, H1-H3 только в треде.
Отправка `raw_markdown` с `@[user_id]` / `+[place_id]` скрытыми id; бэк парсит в связи, отдает `html_safe + entities`.
Санитизация bleach: a/img/strong/em/code/blockquote/ul, режем script/iframe/javascript:.

Рендер `📍`: `<a class=place>name</a>`, ховер/лонгтап → тултип: фото 120px (preview_url или static-map), name, `улица · район`, [Открыть на карте].

## 4. Дизайн-система (массовая, светлая)
XP и темный градиент — выбросить. Светлый clean: bg white/slate-50, карточки white radius-16 shadow-sm border slate-200, акцент lime-600/emerald (наследник lime-400), текст slate-900/500.
Шрифт Inter. Заголовки 16-20, тело 15/1.5.
Мобайл-first: bottom-tabbar 4, тач-зоны 44px, тулбар скролл.
Иконки lucide-react, эмодзи только в тексте юзеров.

## 5. API (план)
```
GET /threads?search=&tags=&has_geo=&is_offtop=&sort=new|top|near&lat=&lng=&radius=&before_id=&limit=
POST /threads {body_md, place_id?, category_ids[], photo_ids[], new_places?[]}
GET /threads/{id} / PATCH /threads/{id} / DELETE /threads/{id}
GET/POST /threads/{id}/comments?sort=
POST /threads/{id}/like / bookmark / view
GET /map/points?bbox=&tags= → [{id,lat,lng,title,has_photo}]
GET /places/search?q= (прокси ЯК + свои) / POST /places (закрепить выбор)
GET /users/search?q= / GET /tags/suggest?q=
```
Старые `/places CRUD v1`, `/posts` — депрекейт read-only, новые не создавать. `cities` — справочник центров.

## 6. Миграция данных
`places v1 → places v5 (kind=self)`, `posts → threads(body_md=text, place_id=place_id)`. Скрипт `migrate_v1_to_v5.py`, даунтайм не важен (MVP).
